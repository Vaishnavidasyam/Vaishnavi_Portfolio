# Vaishnavi Dasyam — Personal Portfolio

A modern, responsive personal developer portfolio showcasing my profile, technical skills, featured engineering projects, documented internships, industry certifications, and contact channels. Built with an editorial dark visual identity (**Noir Radiance**)—combining Jet Black backgrounds, Wine Ash accents, Deep Aubergine surfaces, and Ice Silver typography.

---

## 🌟 Overview

This portfolio serves as a comprehensive professional showcase for **Vaishnavi Dasyam**, a Computer Science Engineer, Full-Stack Developer, and AI/ML Enthusiast. The website is engineered from scratch without bulky third-party frontend frameworks, delivering maximum performance, fast load times, and fluid responsiveness across every screen size.

---

## ✨ Features

- **Responsive Design**: Fluidly adapts across mobile (375px), tablet (768px), and large desktop displays (1280px+) using modern CSS Grid, Flexbox, and CSS clamp typography.
- **Asymmetric Bento Skills Arsenal**: 7 categorized skill domains (Programming, Frontend, Backend, Databases, AI/ML, Mobile, and Developer Tools) presented in an editorial bento grid.
- **Organic Liquid Hero Frame**: Custom asymmetrical profile silhouette featuring multi-layered gradients and subtle outer glow effects.
- **Interactive Project Showcase**: In-depth cards highlighting the University Timetable & Attendance System (UTMS), Mobile Attendance App, and SmartMed Analytics, complete with screenshot preview modals.
- **Experience Timeline**: Documented industry internship milestones with role descriptions, impact metrics, and technology pills.
- **Verified Certifications Grid**: Interactive credential cards with thumbnail previews and direct links to certificates in Cyber Security, Digital Marketing, and AutoCAD Mechanical.
- **Accessibility & Motion Controls**: Built with semantic HTML5 landmarks, full keyboard navigation support, visible focus states, and respect for `prefers-reduced-motion`.
- **Interactive Lightbox Modal**: Click-to-expand image preview modal with keyboard escape closing and body scroll lock.
- **Direct Contact Channels**: One-click email copy-to-clipboard, active mailto links, and verified social links.

---

## 🛠️ Tech Stack

- **HTML5**: Semantic markup, landmark roles, and SVG vector iconography.
- **CSS3**: Custom properties (CSS variables), CSS Grid, Flexbox, responsive clamp typography, and micro-animations.
- **Vanilla JavaScript**: Lightweight interactivity for mobile drawer navigation, scrollspy active link tracking, screenshot lightbox modal, and copy-to-clipboard functionality.

*No external frameworks, CSS libraries (e.g., Tailwind, Bootstrap), or runtime dependencies required.*

## 🚀 Run Locally

You can run this project locally without any build tools, compilers, or package managers:

### Option 1: Direct Browser Launch
1. Clone or download the repository to your local machine:
   ```bash
   git clone https://github.com/Vaishnavidasyam/Vaishnavi_Portfolio.git
   ```
2. Navigate into the project folder:
   ```bash
   cd Vaishnavi_Portfolio
   ```
3. Double-click `index.html` to open it in your default web browser (Chrome, Edge, Firefox, Safari).

### Option 2: VS Code Live Server
1. Open the project folder in Visual Studio Code:
   ```bash
   code .
   ```
2. Install the **Live Server** extension by Ritwick Dey if not already installed.
3. Right-click `index.html` and choose **"Open with Live Server"** (or click **"Go Live"** in the status bar).
4. The site will open at `http://127.0.0.1:5500`.

### Option 3: Python Local HTTP Server
Run the built-in Python web server in your terminal:
```bash
python -m http.server 3000
```
Then navigate to `http://localhost:3000` in your browser.
