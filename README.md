# Vaishnavi Dasyam — Personal Portfolio

A responsive personal portfolio website showcasing my technical skills, projects, internship experience, certifications, and contact information.  
Built with **HTML5, CSS3, and Vanilla JavaScript**.

---

## About the Project

This portfolio presents my background as a Computer Science Engineering student and developer. It features a modern dark-themed design with responsive layouts, interactive elements, and dedicated sections for my professional work.

---

## Features

- **Responsive design** for mobile, tablet, and desktop.
- **Personal introduction and profile section**.
- **Technical skills** organized by category in an editorial bento grid.
- **Featured projects** with repository links and screenshot previews.
- **Internship experience timeline** documenting key roles and impacts.
- **Certifications** with thumbnail previews and links to credentials.
- **Contact information** and verified social profile links.
- **Interactive navigation** with scrollspy active tracking and image preview modals.

## Run Locally

### Prerequisites
- A web browser such as Chrome, Firefox, or Edge.
- Git (optional, if you want to clone the repository).
- Visual Studio Code (optional).

### 1. Clone the repository
Open a terminal and run:
```bash
git clone https://github.com/Vaishnavidasyam/Vaishnavi_Portfolio.git
```

### 2. Navigate to the project folder
```bash
cd Vaishnavi_Portfolio
```

### 3. Run the website

#### Option A — Open directly
Open `index.html` directly in your web browser.

#### Option B — Use Visual Studio Code
Open the project folder in VS Code, install the Live Server extension if needed, and select **Open with Live Server** on `index.html`.

#### Option C — Use Python
If Python is installed, run:
```bash
python -m http.server 3000
```
Then open `http://localhost:3000` in your browser.
